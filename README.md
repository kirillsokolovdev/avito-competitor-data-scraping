# Competitor Radar

Telegram bot for competitor analysis on Avito.

## Features

- Avito scraping with Selenium
- Seller analytics
- Excel export
- Telegram bot interface

## Tech Stack

- Python 3.11
- Aiogram 3
- Selenium
- Pandas
- Openpyxl

## Installation

pip install -r requirements.txt

## Run parser

python parser.py
