# Competitor Radar Bot

🇬🇧 English version: [README.md](README.md)

Telegram-бот для автоматизированного анализа конкурентов на Avito.

Бот собирает объявления с Avito с помощью Selenium, анализирует данные о продавцах и ценах, формирует рыночную статистику и экспортирует результаты в оформленный Excel-отчёт.

Проект был создан как MVP-проект для портфолио с упором на простоту, чистую архитектуру и практическую бизнес-ценность.

Демонстрация работы: https://youtu.be/VPdWqHA9ufM

# Как это работает

## 1. Telegram Bot

Пользователь взаимодействует с ботом через простой FSM flow:

1. Ввод поискового запроса
2. Ввод города
3. Ожидание парсинга и аналитики
4. Получение рыночной сводки
5. Скачивание Excel-отчёта

---

## 2. Модуль парсинга

Парсер:

* запускает Headless Chrome через Selenium;
* открывает страницы поиска Avito;
* динамически прокручивает страницу для загрузки объявлений;
* извлекает:

  * заголовок,
  * цену,
  * имя продавца,
  * рейтинг,
  * количество отзывов,
  * ссылку.

Scraper включает:

* кастомный User-Agent;
* отключённый AutomationControlled flag;
* случайные задержки;
* безопасную обработку ошибок.

---

## 3. Модуль аналитики

Analytics pipeline:

* преобразует сырые данные в Pandas DataFrame;
* очищает и нормализует цены;
* рассчитывает:

  * медианную рыночную цену,
  * минимальную/максимальную цену,
  * лучших продавцов по рейтингу и отзывам;
* экспортирует оформленный Excel файл.

Сгенерированный файл содержит:

* лист со всеми объявлениями;
* лист с краткой сводкой;
* оформление через Openpyxl.

# Установка

## 1. Клонирование репозитория

```bash
git clone https://github.com/kirillsokolovdev/avito-competitor-data-scraping.git
cd avito-competitor-data-scraping
```

---

## 2. Создание виртуального окружения

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Linux / macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

---

## 4. Настройка environment variables

Создайте `.env` файл на основе `.env.example`.

Пример:

```env
BOT_TOKEN=your_telegram_bot_token_here
```

# Пример работы

1. Пользователь отправляет `/start`

2. Бот запрашивает поисковый запрос

3. Пользователь вводит:

   ```
   iPhone 15

4. Бот запрашивает город

5. Пользователь вводит:

   ```

   * отправляет краткое описание и Excel-файл.

# Ограничения

Данная MVP-версия специально сохраняет архитектуру простой.

Текущие ограничения:

* поддерживаются только заранее определённые российские города;
* парсится только первая страница объявлений;
* проект зависит от структуры страниц Avito;
* отсутствует сохранение данных в базе;
* используется только in-memory FSM storage.
